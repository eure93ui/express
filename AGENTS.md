# AGENTS.md — Экспресс-Накладная (Landing & Checkout)

## Общий инсайт проекта
Сайт создается для **не-технарей** (владельцев микробизнеса, ИП, продавцов розницы в РФ). Продукт продает скорость, автономию и отсутствие подписок. Дизайн ориентирован на строгую, аккуратную эстетику уровня **Yaak.app**: чистые линии, высокая контрастность, минимум шума и кричащего маркетинга.

## Пакетный менеджер
- Проект использует **`pnpm`**. Все команды запускать через него (`pnpm dev`, `pnpm build`).

---

## Неизменяемые инварианты (Rules for Agent)

1. **Тональность и тексты (Copywriting):**
   - Только простой, честный русский язык.
   - Запрещен любой технарский/крипто-жаргон. Фокус на ценности: *скорость (30 сек), работа без интернета, защита от споров с покупателями, разовая покупка навсегда*.

2. **Интеграция с приложением (HWID Flow):**
   - Страницы заказа/оплаты (`/buy`) должны корректно считывать GET-параметр `?hwid=...`, переданный из десктопного приложения, и фиксировать его в форме покупки.

3. **Приоритет скачивания:**
   - Главное целевое действие (CTA) сайта — моментальное скачивание установочного **`.exe`** файла без барьеров и лишних форм. Ссылка ведет на прямой статический URL дистрибутива.

4. **Визуальный стиль (UI Vibe):**
   - Наследник Yaak.app: чистый минимализм, разделение контента тонкими бордерами (`border-slate-...`), акцент на реальных скриншотах интерфейса программы вместо мультяшных иллюстраций.
   - Стек верстки: Astro + Tailwind CSS.
