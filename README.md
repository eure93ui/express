# Экспресс-Накладная — Официальный сайт

Официальный сайт программы **«Экспресс-Накладная»** — программы для розничных продавцов и микробизнеса для печати накладных, чеков и ценников за 30 секунд без подписок и интернета.

## Технологии

Сайт построен на базе **Astro** и **Tailwind CSS**.

## Разработка

### Установка зависимостей

```bash
pnpm install
```

### Запуск режима разработки

```bash
pnpm dev
```

### Сборка проекта

```bash
pnpm build
```
